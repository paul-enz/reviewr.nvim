INTRO                                                   *reviewr-intro*

A review opens in a tab of its own: the base on the left, the change on the
right, and every changed file listed along the bottom. Comments sit on lines
or ranges of either side and live in memory until the review closes. Each
records the content its side showed (a commit, the index or the working
tree) and shows only in views of that content.

COMMANDS                                                *reviewr-commands*

  :ReviewrOpen [base] [head] [label]
        No arguments: uncommitted changes. With {base}: the working tree
        against its merge base with {base}. With {base} {head}: the commits
        of {head} against its merge base with {base}. Reviews of the working
        tree cover tracked files only: new files appear once `git add`ed.
  :ReviewrScope {scope}
        uncommitted, staged, branch (the working tree, commits and all,
        against its merge base with the default branch or the one picked
        with gb), commit {sha} (that commit alone) or turn (the
        working tree against the last turn baseline).
  :[range]ReviewrComment {text}
        Comment on the current line or range.
  :ReviewrTurn
        Snapshot the working tree as the turn baseline, in a private
        refs/reviewr/ ref. Nothing else in the repository changes.
  :ReviewrExport [clipboard|send|inbox]
        Export every comment, or none if any is invalid.
  :ReviewrClear
        Drop every comment.

KEYMAPS                                                 *reviewr-keymaps*

In the diff panes:

  c     comment on this line or the selection; :w saves, <esc> cancels
  e     edit the comment under the cursor
  d     delete the comment under the cursor
  n N   next / previous comment
  s     send every comment to the running agent (the paired one, if any)
  S     send, choosing the agent
  y     copy every comment to the clipboard
  l     list comments
  ]c [c next / previous change
  f F   next / previous changed file
  r     reread the changes from git and the working tree
  u b t view: uncommitted / branch / last turn
  gc    pick a commit and review just that commit
  gb    pick the base branch for the branch view
  ?     all keys
  q     close. With unsent comments (new, or edited since the last send or
        copy) it asks once: <CR> closes, <Right> then
        <CR> or <Esc> keeps reviewing. A review that cmd+r
        opened in Rex quits its Neovim, closing the pane

In the changed-files panel, <CR> opens the file under the cursor and q
closes the review. The pickers (gc, gb, S) open a small list: j/k or the
arrows move, <CR> picks, <Esc> cancels.

AGENTS                                                  *reviewr-agents*

`s` pastes the review into a running agent: in a Neovim |terminal|, a tmux
pane, a Rex terminal, or a WezTerm pane. tmux and WezTerm panes must work in
the repository; in Rex, any terminal of Neovim's own session qualifies, and
terminals of other sessions must work in the repository. With several
agents, a picker lists them by terminal title. With none it writes
<repo>/.reviewr/inbox/, and failing that copies to the clipboard. After
sending, the agent's terminal comes forward.

Programs count as agents by the `agents` option. Each comment's heading in
the review names its side and content: `(left, commit <sha>)`,
`(right, working tree)` or `(right, index)`.

A review opened with cmd+r in an agent's Rex terminal is paired with that
agent: s sends to it, and only its turns move the review's own turn baseline.

In Rex the plugin watches the status that agents report. When a watched agent
starts a turn, the turn baseline is snapshotted, so :ReviewrScope turn shows
what that turn changed; when it finishes, the open review reloads. Copies also
go out as OSC 52, which reaches the local clipboard from a remote Neovim.

CONFIGURATION                                           *reviewr-config*

>lua
  require("reviewr").setup({
    baseline_trigger = "auto",   -- agent in Rex, else open; or open, agent,
                                 -- first_comment, manual
    focus_agent = true,          -- bring the agent's terminal forward after s
    refresh_on_agent = true,     -- reload when a watched agent finishes
    send_mode = "queue",         -- queue | submit
    keymaps = true,              -- false, or a table such as { send = "S" }
    adapters = { "neovim-terminal", "tmux", "rex", "wezterm", "filesystem-inbox" },
    agents = { "claude", "codex", "opencode", "aider", "goose", "cline", "pi" },
  })
<

Events fire as |User| autocommands named Reviewr{Setup,Opened,ScopeChanged,
CommentAdded,CommentEdited,CommentDeleted,Exported,ExportFailed,Cleared,
TurnMarked}.
