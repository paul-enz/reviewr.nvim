INTRO                                                   *reviewr-intro*

reviewr is a beautiful code-review companion with clear signs, a status line,
and a comment gutter. Floating review panel toggles all comments.

UI                                                      *reviewr-ui*

KEYMAPS                                                 *reviewr-keymaps*

The footer always shows the next step. `?` lists every key.

  c     comment on the current line, or the visual selection
  s     send every comment to the running agent
  y     copy every comment to the clipboard
  l     list comments
  ]c    next change
  [c    previous change
  ?     all keys
  q     close the review

All buffer-local and remappable through require("reviewr.keymaps").set_defaults().

EXPORT                                                  *reviewr-export*

  require("reviewr.export").export_all(comments, opts)
