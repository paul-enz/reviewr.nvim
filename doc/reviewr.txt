INTRO                                                   *reviewr-intro*

A review opens in a tab of its own: the base on the left, the change on the
right, and every changed file listed along the bottom. Comments sit on lines
or ranges of either side and live in memory until they are sent.

COMMANDS                                                *reviewr-commands*

  :ReviewrOpen [base] [head] [label]
        No arguments: uncommitted changes. With {base} {head}: {head}
        against its merge base with {base}.
  :ReviewrScope {scope}
        uncommitted, staged, branch (default branch...HEAD) or turn (the
        working tree against the last turn baseline).
  :[range]ReviewrComment {text}
        Comment on the current line or range.
  :ReviewrTurn
        Snapshot the working tree as the turn baseline, in a private
        refs/reviewr/ ref. Nothing else in the repository changes.
  :ReviewrExport [clipboard|send|inbox]
        Export every comment, or none if any is invalid.
  :ReviewrClear
        Drop every comment.

KEYMAPS                                                 *reviewr-keymaps*

In the diff panes:

  c     comment on this line or the selection; :w saves, <esc> cancels
  e     edit the comment under the cursor
  d     delete the comment under the cursor
  n N   next / previous comment
  s     send every comment to the running agent
  y     copy every comment to the clipboard
  l     list comments
  ]c [c next / previous change
  f F   next / previous changed file
  r     reread the changes from git and the working tree
  ?     all keys
  q     close; asks first when comments are unsent

In the changed-files panel, <CR> opens the file under the cursor and q
closes the review.

AGENTS                                                  *reviewr-agents*

`s` pastes the review into a running agent: in a Neovim |terminal|, a tmux
pane, a Rex terminal, or a WezTerm pane. tmux and WezTerm panes must work in
the repository; in Rex, any terminal of Neovim's own session qualifies, and
terminals of other sessions must work in the repository. With several
agents, a picker lists them by terminal title. With none it writes
<repo>/.reviewr/inbox/, and failing that copies to the clipboard.

CONFIGURATION                                           *reviewr-config*

>lua
  require("reviewr").setup({
    baseline_trigger = "open",   -- open | first_comment | manual
    send_mode = "queue",         -- queue | submit
    keymaps = true,              -- false, or a table such as { send = "S" }
    adapters = { "neovim-terminal", "tmux", "rex", "wezterm", "filesystem-inbox" },
  })
<

Events fire as |User| autocommands named Reviewr{Setup,Opened,ScopeChanged,
CommentAdded,CommentEdited,CommentDeleted,Exported,ExportFailed,Cleared,
TurnMarked}.
